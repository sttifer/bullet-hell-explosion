# 🚀 Bullet Hell Explosion
Sobreviva ao caos. Evolua seu arsenal. Domine o vazio.
Bullet Hell Explosion é um arcade shooter rítmico e frenético desenvolvido em HTML5. Aqui, a estratégia encontra a adrenalina: a cada horda derrotada, você molda o destino da sua nave com melhorias poderosas. O espaço é perigoso, mas com o power-up certo, você é o perigo.

# 👾 O Desafio
O jogo testa seus reflexos em um ciclo viciante de sobrevivência:
Hordas Infinitas: Ondas de inimigos com dificuldade progressiva.
Sistema de Evolução: Escolha entre upgrades estratégicos após cada onda.
Visual Dinâmico: Explosões e projéteis desenhados para uma experiência imersiva.

# 🕹️ Comandos Adaptáveis
Jogue onde quiser, com máxima fluidez:
No Desktop: Precisão total usando as setas do teclado.
No Mobile: Controle total via touch (a nave segue seu comando instantaneamente).

# 🛠️ Especificações Técnicas
Engine: HTML5 (Instant Play)
Plataformas: Browser (PC, Android, iOS)
Gênero: Bullet Hell / Shoot 'em up
